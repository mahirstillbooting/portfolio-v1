## ⚡ Key Highlights & Features

### 1. Interactive Dot-Matrix Portrait & Wide Field Canvas
- **Full-Span Ambient Starfield:** Flanking particles fade from bright silver/white near the portrait perimeter down to subtle obsidian embers towards screen edges.
- **Magnetic Cursor Dynamics:** Real-time physics engine repelling particles with kinetic spring return and velocity-based thermal heating (`#E2652B` amber and `#D71921` crimson glow).
- **S-Curve Tornado Vortex:** Click-triggered multi-rotation vortex simulation accompanied by synthesized Web Audio API sound waves and expanding shockwave pulses.
- **Scroll-Triggered Dispersion:** GSAP-driven particle dispersal that scatters elements outward as you scroll through the editorial hero stage.

### 2. Borderless 3D Holographic Project Orbital (Three.js + GSAP)
- Seamless canvas hosting 5 interactive 3D holographic monoliths for flagship builds (*ChalokApp, ARS System, Ivory Pastry, Smart Waste Dhaka, Book Shop DB*).
- Real-time mouse dragging, inertia damping, left/right keyboard cycling, and smooth GSAP camera targeting.
- Hover states with chromatic edge beveling, floating coordinate halos, and status pings.

### 3. Editorial Layout & Bento Grid
- **Typography:** Harmonious contrast between *Instrument Serif* italic headlines, *Geist Sans* reading typography, and *Geist Mono* for telemetry and metadata.
- **12-Column Responsive Bento Grid:** Structured project case studies with micro-summaries, live metrics, tech badges, and direct repository links.
- **Live Dhaka HUD:** Real-time GMT+6 clock, location coordinates (`23.8103° N, 90.4125° E`), and system telemetry.

### 4. Floating Frosted Glass Navbar
- Fixed pill navbar with backdrop blur (`blur(20px)`), keyboard navigation hotkeys, and quick mailto action.

## 🚀 Quickstart & Development

### Prerequisites
- Node.js `20.x` or higher
- npm `10.x` or higher

```bash
# Clone the repository
git clone https://github.com/mahirstillbooting/portfolio-v1.git
cd portfolio-v1

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to view the application.

### Production Build
```bash
# Typecheck and compile production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deployment to GitHub Pages

This repository includes a continuous deployment workflow configured at `.github/workflows/deploy.yml`.

1. Push your changes to the `main` branch.
2. In your repository on GitHub, navigate to **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. The workflow will automatically compile and deploy your site to `https://mahirstillbooting.github.io/portfolio-v1/`.
